## ១. សេចក្ដីផ្ដើមអំពី Microcontroller (MCU)

**Microcontroller (MCU)** គឺជាប្រព័ន្ធកុំព្យូទ័រខ្នាតតូចមួយដែលត្រូវបានបង្រួមបញ្ចូលគ្នានៅលើបន្ទះ Integrated Circuit (IC) តែមួយ។ ខុសពី Microprocessor (CPU លើកុំព្យូទ័រ) ដែលត្រូវការ RAM, ROM, និង I/O Chips ភ្ជាប់បន្ថែមពីក្រៅ MCU មានផ្ទុកគ្រឿងបង្គុំស្នូលទាំងអស់នៅក្នុងខ្លួនរួចជាស្រេច៖

* **Processor Core (CPU):** អង្គគណនា និងប្រតិបត្តិពាក្យបញ្ជា (ALU, Control Unit)
* **អង្គចងចាំ (Memory):**
  * **Flash Memory (ROM):** រក្សាទុកកូដកម្មវិធី (Program Code)។ ទិន្នន័យមិនបាត់បង់ទេពេលដាច់ភ្លើង (Non-volatile)។
  * **SRAM (Static RAM):** រក្សាទុកអថេរ (Variables) និងដំណើរការគណនាបណ្តោះអាសន្ន។ ទិន្នន័យនឹងបាត់បង់ពេលដាច់ភ្លើង (Volatile)។
  * **EEPROM:** អង្គចងចាំខ្នាតតូចសម្រាប់រក្សាទុកការកំណត់ (Settings, Calibration Data) ដោយមិនបាត់បង់ពេលដាច់ភ្លើង។
* **ឧបករណ៍ភ្ជាប់ខាងក្រៅ (Peripherals):** GPIO (Digital I/O), ADC, Timers, UART, I2C, SPI, និង PWM Generators។

## ២. ស្ថាបត្យកម្ម ATmega328P (Arduino Uno)

Arduino Uno ដំណើរការដោយបន្ទះឈីប 8-bit AVR RISC ឈ្មោះ **ATmega328P** ដែលមានលក្ខណៈបច្ចេកទេសសំខាន់ៗដូចខាងក្រោម៖

| លក្ខណៈបច្ចេកទេស (Specification) | តម្លៃ / ទំហំ |
| :--- | :--- |
| **ស្ថាបត្យកម្ម (Architecture)** | 8-bit AVR RISC |
| **ល្បឿន Clock (Operating Frequency)** | 16 MHz (Crystal Oscillator) |
| **វ៉ុលដំណើរការ (Operating Voltage)** | 5V DC |
| **Flash Memory** | 32 KB (ក្នុងនោះ 0.5 KB ប្រើដោយ Bootloader) |
| **SRAM** | 2 KB |
| **EEPROM** | 1 KB |
| **ជើង Digital I/O** | 14 ជើង (ក្នុងនោះ 6 ជើងជាជើង PWM) |
| **ជើង Analog Input (ADC)** | 6 ជើង (កម្រិតច្បាស់ 10-bit: 0 ដល់ 1023) |
| **ចរន្តអតិបរមាក្នុងមួយជើង (DC Current per I/O Pin)** | 20 mA (ដាច់ខាតកុំឱ្យលើស 40 mA) |

## ៣. តួនាទីរបស់ Bootloader

នៅក្នុងប្រព័ន្ធ Microcontroller ទូទៅ ការបញ្ចូលកូដទាមទារឧបករណ៍ដុតកម្មវិធីខាងក្រៅ (In-System Programmer ដូចជា USBasp ឬ AVRISP) ភ្ជាប់ទៅកាន់ជើង ICSP (MISO, MOSI, SCK, RESET)។

**Bootloader** គឺជាកូដកម្មវិធីតូចមួយដែលត្រូវបានដុតបញ្ចូលជាមុននៅក្នុងប្លុក Flash Memory ពិសេសនៃបន្ទះឈីប ATmega328P៖
1. នៅពេលចុច Reset ឬបើកភ្លើង Bootloader នឹងរង់ចាំពីរបីមិល្លីវិនាទីដើម្បីពិនិត្យមើលថាតើមានកូដថ្មីផ្ញើមកតាមច្រក USB (Serial UART) ដែរឬទេ?
2. ប្រសិនបើមាន វានឹងទាញយកកូដថ្មីនោះទៅសរសេរជាន់លើ Flash Memory ដោយស្វ័យប្រវត្តិ។
3. ប្រសិនបើគ្មានកូដថ្មីទេ វានឹងហោះទៅដំណើរការកូដកម្មវិធីមេរបស់សិស្សភ្លាមៗ។
> យន្តការនេះហើយដែលធ្វើឱ្យ Arduino ងាយស្រួលប្រើប្រាស់ ព្រោះគ្រាន់តែដោតខ្សែ USB មួយខ្សែគឺអាចទាំងផ្គត់ផ្គង់ភ្លើង និង Upload កូដបានភ្លាមៗ។
