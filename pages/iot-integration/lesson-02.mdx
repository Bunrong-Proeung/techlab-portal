# មេរៀនទី ២៖ Digital Input/Output និងសៀគ្វីចំណុចប្រទាក់

---

## ១. ស្ថាបត្យកម្មខាងក្នុងនៃ GPIO Pins

ជើង GPIO នីមួយៗនៅលើ ATmega328P ត្រូវបានគ្រប់គ្រងដោយសៀគ្វីអេឡិចត្រូនិកខាងក្នុងដែលមាន៖
* **Output Driver:** ផ្គត់ផ្គង់ចរន្ត Source (5V) ឬ Sink (GND)
* **Input Buffer (Schmitt Trigger):** បម្លែងកម្រិតវ៉ុលឱ្យទៅជា Logic HIGH ឬ LOW ដាច់ណាត់
* **Internal Pull-Up Resistor:** រេស៊ីស្តង់ខាងក្នុងចន្លោះពី 20k Ohm ទៅ 50k Ohm ដែលអាចបើក ឬបិទបានតាមកូដ

---

## ២. ការគណនា Current-Limiting Resistor សម្រាប់ LED

### រូបមន្តគណនាតាមច្បាប់អូម (Ohm's Law):
```* **Vcc:** វ៉ុលផ្គត់ផ្គង់ចេញពី Pin (5V)
* **Vf:** វ៉ុលធ្លាក់កាត់ LED (អំពូលក្រហមប្រហែល 1.8V ដល់ 2.0V)
* **If:** ចរន្តសមស្រប (10mA ដល់ 20mA ឬ 0.01A ដល់ 0.02A)

**ឧទាហរណ៍គណនាសម្រាប់ LED ពណ៌ក្រហម (Vf = 2.0V, If = 15mA):**
*(អាចជ្រើសរើសរេស៊ីស្តង់តម្លៃស្ដង់ដារ 220 Ohm ឬ 330 Ohm)*

## ៣. ស្ថានភាព Floating Input និង Pull-up / Pull-down

នៅពេលកំណត់ជា Input ប្រសិនបើជើងមិនភ្ជាប់ទៅប្រភពភ្លើង ឬដី វានឹងស្ថិតក្នុងស្ថានភាព Floating (អណ្ដែត) ដែលធ្វើឱ្យ Logic លោតញាក់មិនទៀងទាត់។

### យន្តការទប់ស្កាត់៖
1. **External Pull-down Resistor:** ភ្ជាប់រេស៊ីស្តង់ 10k Ohm ពីជើង Input ទៅ GND (ស្ថានភាពធម្មតា = LOW)
2. **External Pull-up Resistor:** ភ្ជាប់រេស៊ីស្តង់ 10k Ohm ពីជើង Input ទៅ 5V (ស្ថានភាពធម្មតា = HIGH)
3. **Internal Pull-up (INPUT_PULLUP):** ប្រើរេស៊ីស្តង់ខាងក្នុងបន្ទះឈីប ដោយមិនបាច់តខាងក្រៅ (ស្ថានភាពធម្មតា = HIGH, ពេលចុច = LOW)

## ៤. បាតុភូត Contact Bouncing និង Software Debouncing

បន្ទះលោហៈនៃប៊ូតុងចុចនឹងលោតញាក់ (Bounce) ទៅមកក្នុងរយៈពេលខ្លី (1ms ដល់ 10ms) នៅពេលចុច ឬលែង។

### កូដគំរូទប់ស្កាត់ (Software Debounce):
void setup() {
  pinMode(BUTTON_PIN, INPUT_PULLUP);
  Serial.begin(9600);
}

void loop() {
  int reading = digitalRead(BUTTON_PIN);

  if (reading != lastButtonState) {
    lastDebounceTime = millis();
  }

  if ((millis() - lastDebounceTime) > debounceDelay) {
    if (reading != buttonState) {
      buttonState = reading;

      if (buttonState == LOW) {
        Serial.println("Valid Button Press Detected!");
      }
    }
  }

  lastButtonState = reading;
}
