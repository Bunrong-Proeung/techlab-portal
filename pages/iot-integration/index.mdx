# IoT Integration Systems

មគ្គុទ្ទេសក៍ការអនុវត្តប្រព័ន្ធ Internet of Things (ESP32, Sensors, និង Cloud MQTT)។

### មាតិកាអនុវត្ត
* **Module 01:** ESP32 GPIO, ADC & Sensor Interfacing (DHT22, Soil Moisture)
* **Module 02:** Cellular Communication (SIM7600 / A7670 AT Commands)
* **Module 03:** MQTT Protocol & Node-RED Dashboard
* **Module 04:** Automated Field Controller Deployment
