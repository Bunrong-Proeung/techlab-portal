## 📌 ការណែនាំសម្រាប់ការអនុវត្ត Lab

ដើម្បីឱ្យការអនុវត្តក្នុងបន្ទប់ពិសោធន៍ទទួលបានប្រសិទ្ធភាពខ្ពស់ និស្សិតទាំងអស់ត្រូវ៖

1. **រៀបចំមុនពេលចូលរៀន (Pre-Lab):** អានឯកសារណែនាំ Lab Guide និងធ្វើការគណនាទ្រឹស្ដីជាមុន។
2. **ត្រៀមកម្មវិធីពិសោធន៍ (Software Prerequisites):**
   * **Cisco Packet Tracer (v8.x ឡើងទៅ)** សម្រាប់មុខវិជ្ជា Routing & Switching
   * **NI Multisim** សម្រាប់មុខវិជ្ជា Analog Electronics
   * **VS Code / Arduino IDE / PlatformIO** សម្រាប់មុខវិជ្ជា IoT Integration
3. **ការផ្ញើរបាយការណ៍ (Lab Report):** រៀបចំលទ្ធផលវាស់វែង រូបភាព Waveform/Topology និងសេចក្ដីសន្និដ្ឋានទៅតាមទម្រង់ដែលបានកំណត់ក្នុងមេរៀននីមួយៗ។
