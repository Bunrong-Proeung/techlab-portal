# 🛠️ Tools & Development Setup

សូមស្វាគមន៍មកកាន់ផ្នែក **Tools & Setup**! ផ្នែកនេះត្រូវបានរៀបចំឡើងដើម្បីណែនាំការដំឡើង Software, Extension, Drivers និងឧបករណ៍ជំនួយចាំបាច់នានា មុនពេលចាប់ផ្តើមអនុវត្តការពិសោធន៍ជាក់ស្តែង។

---

### 📌 ឧបករណ៍ចាំបាច់ក្នុងការសិក្សា

1. **កម្មវិធីសរសេរកូដ (Code Editors):**
   - **Visual Studio Code** រួមជាមួយ **PlatformIO IDE** (សម្រាប់សរសេរ និង Upload កូដ ESP32 / Arduino)
   - **Arduino IDE 2.x** (សម្រាប់តេស្តសាកល្បងលឿនៗ)

2. **USB to UART Drivers:**
   - **CH340 / CH341 Driver** (បន្ទះ ESP32 ភាគច្រើន)
   - **CP210x Driver** (Silicon Labs)

3. **កម្មវិធីគូសប្លង់សៀគ្វី (EDA Tools):**
   - **KiCad 8.x** (សម្រាប់គូស Schematic និង Design PCB)
   - **NI Multisim** (សម្រាប់ Simulation សៀគ្វី Analog)
